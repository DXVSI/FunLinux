# otherFishFunc

Различные полезные функции для Fish Shell, которые не вошли в другие категории.

## Функции

### bios

Быстрая перезагрузка в BIOS/UEFI Setup.

**Использование:**
```bash
bios
```

**Что делает:**
- Использует `systemctl reboot --firmware-setup`
- Перезагружает систему напрямую в настройки BIOS/UEFI
- Работает на системах с UEFI

### upd

Обновление всей системы одной командой: пакеты dnf, Flatpak, прошивки и пользовательские инструменты. Обновляется только то, что установлено. Каждый шаг выводится в отдельной рамке с номером и временем, в конце печатается итоговая таблица и сообщение, если нужна перезагрузка. Ошибка в одном источнике не останавливает остальные.

**Использование:**
```fish
upd                     # обновить всё, что найдено
upd firefox chromium    # только эти пакеты dnf, как раньше
upd -o flatpak,npm      # только выбранные источники
upd -s fwupd            # всё, кроме прошивок
upd -c                  # обновить и удалить ненужное
upd -l                  # какие источники найдены и почему пропущены остальные
upd -h                  # справка
```

**Параметры:**

| Параметр | Что делает |
|---|---|
| `-o, --only СПИСОК` | только эти источники, через запятую или несколькими флагами |
| `-s, --skip СПИСОК` | пропустить источники |
| `-y, --yes` | не спрашивать подтверждение у fwupd |
| `-c, --clean` | `dnf autoremove`, удаление неиспользуемых Flatpak runtime, `brew cleanup` |
| `-l, --list` | показать источники и их состояние |

**Источники** (в порядке выполнения):

| Источник | Команда | Когда используется |
|---|---|---|
| `dnf` | `sudo dnf5 upgrade --refresh -y` | всегда на Fedora |
| `flatpak` | `flatpak update -y` | установлен flatpak, обновляет system и user |
| `snap` | `sudo snap refresh` | установлен snap |
| `brew` | `brew upgrade` | установлен Homebrew |
| `uv` | `uv tool upgrade --all`, `uv self update` | есть инструменты uv; self update только для установки через установщик uv |
| `pipx` | `pipx upgrade-all` | установлен pipx |
| `npm` | `npm install -g пакет@latest` для устаревших | глобальный prefix npm доступен на запись без sudo |
| `bun` | `bun upgrade` | bun установлен в `~/.bun` |
| `rustup` | `rustup update` | установлен rustup |
| `cargo` | `cargo install-update -a` | установлен `cargo-update` |
| `gh` | `gh extension upgrade --all` | есть расширения GitHub CLI |
| `fisher` | `fisher update` | установлен fisher |
| `claude` | `claude update` | нативная установка Claude Code |
| `fwupd` | `fwupdmgr refresh`, `get-updates`, `update` | установлен fwupd |

**Детали:**
- sudo запрашивается один раз в начале, если в очереди есть dnf или snap.
- Для npm используется `npm outdated -g` и установка `@latest`, потому что `npm update -g` не переходит на новую major-версию, а для пакетов `0.x` и на новую minor.
- fwupd идёт последним: без `-y` он сам спрашивает подтверждение перед прошивкой. Перезагрузку `upd` не запускает, только сообщает о ней.
- После dnf перезагрузка определяется через `dnf5 needs-restarting` (пакет `dnf5-plugins`).
- Код возврата 0, если все шаги прошли успешно, иначе 1.

### cat

Замена стандартного cat на bat с подсветкой синтаксиса.

**Использование:**
```bash
# Просмотр файла с подсветкой
cat file.js

# Все возможности bat
cat -n file.py  # с номерами строк
cat -A file.sh  # показать непечатаемые символы
```

**Особенности:**
- Автоматическая подсветка синтаксиса для 200+ языков
- Интеграция с git для отображения изменений
- Нумерация строк
- Постраничный вывод для больших файлов

**Требует:** Пакет `bat`

## Установка

```bash
# Скопировать функции в директорию Fish
cp otherFishFunc/*.fish ~/.config/fish/functions/

# Перезагрузить Fish
exec fish
```

## Примеры

```bash
# Быстрая перезагрузка в BIOS
bios

# Обновить всё: dnf, Flatpak, прошивки и инструменты
upd

# Обновить конкретный пакет
upd kernel

# Просмотр файла с подсветкой синтаксиса
cat script.fish
```

## Совместимость

- **bios**: Требует systemd и UEFI
- **upd**: Fedora с dnf5 (Fedora 41+) или dnf; остальные источники подключаются, если установлены. Fish 3.4+
- **cat**: Требует bat (устанавливается автоматически через dnfish)
